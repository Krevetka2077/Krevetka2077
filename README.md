## Направления

- **Финансы:** анализ отчётности, денежных потоков и рисков; инвестиционные инструменты и портфельный анализ.
- **Бизнес-анализ:** сбор и структурирование требований, моделирование процессов с BPMN, UML и IDEF0.
- **Данные:** Python, SQL, PostgreSQL, SQL Server, Excel и аналитические прототипы.
- **AI:** LLM, RAG, embeddings, семантический поиск, векторные базы данных и интеграции через API.
